Data use

Privacy information

Unified Email Manager is operated as a personal application. This statement describes its supported data flows.

Google data accessed

When authorized, the application reads Gmail messages and metadata, including senders, subjects, message text, identifiers and labels. Its email workflows can update labels, read flags and mailbox placement under the operator’s approved rules and decisions.

Calendar-reading authorization permits access to calendar information and events. A separate event-access authorization permits the application’s event workflows on calendars covered by that permission. The application checks that the signed-in identity matches the configured account.

How the information is used

Data supports mailbox previews, approved cleanup rules, calendar views, reviewed event workflows, local reminders, and optional assistant features. Optional AI assistance uses a locally installed model; enabled examples and feedback are used as local application context rather than for training model weights.

Storage and backups

Refresh credentials are stored in the operating system credential store. On the Ubuntu deployment, this is the encrypted login keyring. Cached mailbox and calendar information, rules, reminders and workflow records are stored locally. Rotating backups can include configuration and cached application data; those application backups exclude account credentials and OAuth client-registration files. Removing an active record does not automatically erase older backup copies.

Sharing and service providers

The application communicates with Google to perform authorized Google operations. Other configured mailbox and calendar providers receive requests for their connected accounts. When private Telegram features are enabled, notification details, calendar reports and explicitly requested assistant information can be sent to the operator’s paired private Telegram chat. Telegram then processes that information under its own policies.

The public information pages contain no mailbox integration, sign-in form, advertising or analytics scripts. The website hosting provider can process ordinary technical request data, such as IP addresses and access logs.

Control and revocation

The operator can pause automation and phone delivery, review permissions, and revoke the application’s Google access through Google account permissions. Revocation stops future authorized access; local cached data and backups require separate review or removal.

Limited use and contact

Google user data is used for the application’s stated personal productivity features, not for advertising, sale or general-purpose model training. The application’s use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

For questions, use the support email displayed on the Google consent screen. This statement must be reviewed if the operator changes the application’s data use or adds services.
